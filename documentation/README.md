# Documentation technique

Ce dossier décrit les données, les règles de préparation et les limites de l'analyse des infrastructures de recharge pour véhicules électriques (IRVE).

## Documents prévus

- `methodologie.md` : étapes de nettoyage et règles de sélection des déclarations.
- `dictionnaire-donnees.md` : description des principales colonnes de la table analytique.
- `qualite-donnees.md` : valeurs manquantes, doublons et contradictions détectées.

## Principes méthodologiques

- Conserver les données brutes sans les modifier.
- Distinguer les points de charge identifiés de manière fiable des déclarations sans identifiant exploitable.
- Sélectionner une déclaration de référence selon des règles explicites.
- Signaler les contradictions sans prétendre les résoudre automatiquement.
- Distinguer les valeurs inconnues des réponses négatives.
- Documenter les limites des données utilisées pour les visualisations.

Les documents détaillés seront ajoutés après vérification des scripts et des résultats du projet.
